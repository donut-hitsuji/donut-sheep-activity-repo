Preset / Beat Sync Help

Beat Sync 共通パラメータ

  • Division: 何拍ごとに反応するか。1拍、2拍、1小節など。
  • Phase: 拍をどれだけずらすか。裏拍なら0.5付近。
  • Depth: 拍同期効果の深さ。イベント強度と掛け合わせます。
  • Decay: 拍頭から何msで戻すか。短いほどクリック的、長いほど揺れます。
  • Beat curve: sharpは鋭く、smoothは自然、bounceは少し跳ねます。
  • Alternate: 左右交互、前後交互、奇数/偶数拍限定など。
  • 基準 X/Y/Z: Beat Syncの定位変化やorbitの中心位置です。トラックイベントは未設定時にトラック基本位置、セクションイベントは中央付近を初期値にします。

Beat Sync プリセット

  • beat_pan_alternate: 拍ごとに左右へ定位を揺らします。アドリブ、SE、薄いシンセ向き。
  • beat_gain_pulse: 拍頭だけ音量を少し押します。やりすぎるとポンピングします。
  • beat_reverb_throw: 拍頭だけ短くリバーブ送信を上げます。装飾音や語尾向き。
  • beat_width_pulse: 拍でステレオ幅を開閉します。コーラスやパッド向き。
  • downbeat_focus: 小節頭だけ中央・近め・少し明瞭に寄せます。展開の頭を強調します。
  • orbit_on_bar: 1小節周期でゆっくり周回します。主ボーカルより装飾音向き。

通常プリセット

  • whisper_close_left/right: 耳元寄りの囁き配置。
  • walk_in_front / walk_away_front: 前後方向の接近・遠ざかり。
  • pass_left_to_right / pass_right_to_left / pass_behind: 横切りや背後通過。
  • chorus_widen: コーラスやハモリを広げます。
  • adlib_flyby: 短いアドリブやSEを横に抜けさせます。
  • custom_space_path: 2D Space Viewで作成した独自移動。
