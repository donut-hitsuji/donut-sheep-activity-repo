音楽ジャンル地図

前に作った「見落とし防止用の大分類」を軸に、Sunoで使える英語タグまで落とし込みました。チップをクリックすると下のPrompt Basketに入ります。

分類は絶対的な系統樹ではなく、タグの重なりです。迷ったら「主役ジャンル2つ + スパイス1〜2つ + 楽器 + 空間」で組むと薄まりにくいです。

Western Classical / Art Music

西洋クラシック・芸術音楽

時代・形式・編成で指定するとSunoが迷いにくい領域。'neoclassical'は文脈で意味が変わるので、piano/chamber/darkwave/metalなどを併記する。

時代 / Period音色よりも和声・形式・装飾の方向を決める。
形式 / Formクラシックはジャンル名より形式名が強い。
宗教・声楽形式荘厳さや儀礼性を一気に出す。
近現代・クロスオーバー生成AIではここを具体化しないと曖昧になる。

Suno prompt examples

modern neoclassical piano, intimate solo piano, minimal strings, melancholic, close room sound
baroque chamber music, harpsichord, violin counterpoint, elegant ornaments, candlelit atmosphere
requiem-inspired choral music, low organ drone, mixed choir, solemn sacred atmosphere

Sacred / Ritual / Devotional

宗教・儀礼・祈りの音楽

声を束ねる、反復する、空間に漂わせる。ジャンル名に加えてunison, monophonic, drone, responsorialを足すと狙いやすい。

キリスト教系無伴奏・単旋律・残響の方向。
イスラム / スーフィー系ナシード、ズィクル、リード＋合唱の陶酔。
南アジア・バクティ系反復、コール＆レスポンス、ハルモニウム/タブラが相性良い。
仏教・東アジア系間、低声、長い残響。
ユダヤ・他儀礼無詞反復や朗誦を足すと宗教色を保ちやすい。

Suno prompt examples

devotional nasheed, male unison chant, monophonic, sparse frame drum, low drone, reverent
Sufi qawwali, lead singer with chorus refrains, harmonium, tabla, hand claps, ecstatic devotional energy
Japanese shōmyō, low male ritual chant, temple resonance, slow meditative tempo, sparse drone

Folk / Traditional / World

民俗・伝統・地域音楽

地域名 + 代表楽器 + 拍/儀礼/踊りの文脈をセットで書く。'world music'単体は薄いので具体化する。

ヨーロッパ民俗笛・弦・舞曲・ドローン。
中東・北アフリカ旋法、撥弦、フレームドラム。
南アジアラーガ、ドローン、タブラ系。
東・東南アジア雅楽、ガムラン、弦と笛の色。
アフリカポリリズム、コール＆レスポンス、親指ピアノ/コラ。
アメリカ大陸・カリブ踊り、打楽器、混交文化。

Suno prompt examples

mystical desert folk, oud, ney flute, frame drum, hand claps, warm drone, modal melody
Nordic dark folk, hardanger fiddle, nyckelharpa, low drone, ritual percussion, cold atmosphere
Japanese ceremonial ambient, shō mouth organ drone, hichiriki-like reed melody, low taiko, temple bells

Jazz / Blues / Gospel

ジャズ・ブルース・ゴスペル

コード感、即興感、声の熱量。Sunoでは楽器編成と年代/地域を添えるとかなり変わる。

Bluesギター、12小節、泥臭さ。
Jazz: 伝統〜モダン年代と編成で指定。
Jazz: クロスオーバー電子/ファンク/クラブとの接続。
Gospel / Roots vocal合唱・ハンドクラップ・教会感。

Suno prompt examples

late-night modal jazz, upright bass, brushed drums, muted trumpet, smoky piano chords
raw Delta blues, slide guitar, foot stomp, weathered male vocal, dusty analog recording
modern gospel choir, hand claps, Hammond organ, soulful lead vocal, uplifting chorus

R&B / Soul / Funk

R&B・ソウル・ファンク

グルーヴ、ベース、ボーカルの艶。古い年代を指定するとMotown/doo-wop、新しめならneo-soul/contemporary R&Bへ寄る。

R&B rootsロックンロールやソウルの源流にも接続。
Soulボーカル表現とホーン/オルガン。
Funk / Discoベースとリズムギターを強く。
Modern R&B808, trap drums, airy vocal padと相性。

Suno prompt examples

neo-soul, warm Rhodes piano, laid-back bass, intimate female vocal, brushed drums, smoky chords
70s funk, slap bass, tight rhythm guitar, horn stabs, clavinet, danceable groove
quiet storm R&B, soft electric piano, silky vocal harmonies, slow groove, late-night atmosphere

Rock / Pop / Alternative

ロック・ポップ・オルタナティブ

一番広く混ざりやすい領域。Sunoではギターの歪み量、コーラスの形、時代感、地域感を明記する。

Rock roots / classicバンド編成と年代感。
Art / Alternative / Indie雰囲気や質感で分岐。
Popメロディ中心。地域や時代を添える。
日本/東アジアシーンSunoで強いプロンプト語が多い。
歌声・コーラス方向“ポップ”の中身を決める。

Suno prompt examples

genre-blending J-pop, shoegaze guitars, idol chorus, neoclassical strings, dramatic anime opening energy
dream pop, clean guitars, airy female vocal, lush reverb, soft synth pads, bittersweet melody
visual anime rock, melodic lead guitar, punchy drums, soaring chorus, dramatic key changes

Punk / Metal / Gothic

パンク・メタル・ゴシック

攻撃性、暗さ、劇的さを調整する領域。Gothicはrock/darkwave/metal/neoclassicalで別物になる。

Punk / Hardcore速度、荒さ、政治性。
Post-punk / Gothic暗い低音、冷たいギター、耽美。
Metal: 基本系ギターの歪みとドラムの激しさ。
Metal: 現代/混成ジャンル融合しやすい枝。
雰囲気語ジャンル名だけでは足りない暗さを補う。

Suno prompt examples

neoclassical darkwave, chamber strings, pipe organ drone, ethereal choir, gothic atmosphere
gothic metal, distorted guitars, symphonic strings, female lead vocal, heavy drums, cathedral reverb
post-punk darkwave, cold bassline, chorus guitar, detached vocal, smoky underground club

Hip-Hop / Rap / Spoken

ヒップホップ・ラップ・スポークン

ビート様式、フロウ、サンプル感で分ける。Spoken/Audioは音楽外に寄るので、poetic, narrative, documentaryなどを併記する。

Classic / Sample-basedドラム、サンプル、低域。
Modern rap808、ハイハット、空間。
地域・クロスオーバー英語圏以外を指定したい時。
Spoken / AudioLuminate/Discogs系の音楽外カテゴリーも拾う。

Suno prompt examples

jazz rap, dusty piano sample, boom bap drums, upright bass loop, thoughtful spoken flow
dark drill, sliding 808 bass, sparse piano, rapid hi-hats, ominous urban atmosphere
spoken word over ambient drone, intimate narration, subtle pulse, cinematic documentary mood

Electronic / Dance / Experimental

電子音楽・ダンス・実験

BPM・キック・シンセの種類・空間で変化が大きい。EDMだけだと広すぎるのでhouse/techno/ambientなどに分解する。

Ambient / Downtempo拍を弱く、空間を強く。
House / Techno / Trance四つ打ちの主要分岐。
Breakbeat / Bassブレイク、サブベース、速度。
Industrial / Experimental硬質、ノイズ、機械感。
Internet / Contemporary electronicSunoの生成では強いタグ。

Suno prompt examples

dark ambient, low drone, granular texture, distant bells, slow evolving pads, no drums
liquid drum and bass, fast breakbeats, warm sub bass, atmospheric pads, soulful vocal chops
industrial techno, pounding kick, metallic percussion, EBM bassline, cold warehouse reverb

Media / Functional / Scene Music

映像・用途・シーン音楽

ジャンルではなく“使われる場面”を指定する軸。生成AIではとても効く。映画、ゲーム、儀式、児童、環境音など。

Screen / Stage映像と舞台。
Japanese scene tags日本のシーン文化は音像に直結する。
Functional / UtilityMusicmapがPopular以外として挙げるUtility的領域。
Holiday / Ritual / Event用途を示すだけで構成が変わる。
Non-music / NEARS自然音・効果音・ASMRなど。音楽と混ぜると面白い。

Suno prompt examples

dark fantasy game soundtrack, low strings, duduk lead, frame drum, choir pad, cinematic reverb
anime idol opening, bright synth bells, energetic drums, group chorus, dramatic key change
relaxation ambient, soft synth pad, rain field recording, distant piano, slow breathing space

Hybrid / Crossover / Genre-Bending

ジャンル混成・ごちゃまぜ軸

ジャンルを混ぜるための横断語。主役ジャンル2つ、スパイス1〜2つ、質感語でまとめると薄まりにくい。

自然に混ぜる違和感少なめ。
境界を壊す今っぽい越境感。
様式を衝突させる高級・実験音楽っぽい。
Sunoでの配合ルール平均化させないための配合比。

Suno prompt examples

genre-bending fusion, J-pop idol chorus, gothic rock guitars, neoclassical strings, industrial drums, dramatic and dark
polystylistic experimental pop, sacred chant intro, breakcore drums, gothic metal guitars, idol J-pop chorus
eclectic devotional fusion, nasheed-like male chant, oud, frame drum, gothic strings, electronic bass

楽器地図

楽器は「何で鳴るか」と「曲中で何をするか」を分けると強いです。Hornbostel–Sachs的な発音原理、オーケストラ編成、地域パレット、Suno向け役割を横断できます。

Sunoでは楽器名だけでなく、lead / drone / rhythm / bass / sparkle / texture の役割語を添えると結果が安定します。

Idiophones / 体鳴楽器

楽器本体が鳴る。金属・木・石などの物体そのものの振動で、きらめき、儀式感、民族感を足す。

Struck / 打つ一番基本。硬さと残響を決める。
Shaken / 振るリズムの粒、民俗感。
Scraped / Friction / 擦る不穏・儀式・効果音。
Plucked lamellae / 弾く体鳴柔らかい民族的きらめき。

Suno prompt examples

ritual ambient, low gong, singing bowls, distant bells, cavernous reverb
mystical folk texture, kalimba, handpan, soft shakers, warm acoustic room

Membranophones / 膜鳴楽器

張った膜が鳴る。儀式性、身体性、拍の重さを決める。ナシード/儀礼系ではframe drum, daf, duffが強い。

Frame drums / 枠太鼓宗教・儀礼・中東・ケルトに強い。
Hand drums / 手で叩くグルーヴや民族感。
Orchestral / Band drums西洋的な緊張と迫力。
Large ritual drums低域、儀式、戦闘、祭り。
Friction / Mirliton特殊枠。kazooは膜で声を変える。

Suno prompt examples

devotional chant, male unison voices, sparse daf, low drone, hand claps, reverent
festival taiko ensemble, huge low drums, synchronized hits, ceremonial energy

Chordophones / 弦鳴楽器

弦が鳴る。旋律、伴奏、ドローン、低域、装飾の全部を担える。地域名と奏法を足すと強い。

Bowed strings / 弓で弾く歌う旋律・泣き・荘厳。
Plucked lutes / 撥弦リュート系地域の匂いが出やすい。
Zithers / ツィター系水平に張った弦。ドローンやきらめき。
Drone strings宗教/瞑想/古楽で重要。
Keyboard strings鍵盤だが発音は弦。

Suno prompt examples

Persian santur, shimmering hammered strings, delicate ornamentation, warm room reverb
melancholic solo cello, high register melody, soft tremolo strings, intimate neoclassical mood
desert folk, oud lead, qanun ornaments, ney flute, frame drum, modal melody

Aerophones / 気鳴楽器

空気が鳴る。息、祈り、遠景、英雄感。フルート系、リード系、金管、自由リード、オルガンで役割が大きく変わる。

Flutes / Edge-blown息、透明感、東洋感。
Reeds / 木管リード哀愁、鼻にかかる音、民族性。
Lip-reed / Brass英雄、軍楽、荘厳。
Free reed持続音・民俗・祈り。
Organs / Bagsドローンと空間。

Suno prompt examples

Armenian duduk lead, low drone, frame drum, cinematic desert melancholy
ancient Japanese court music, shō drone, hichiriki reed melody, ryūteki flute, ceremonial pacing
cathedral organ, deep pedal drone, sacred choir, solemn reverb

Electrophones / 電鳴・電子楽器

電気・電子的に音を作る/変える。GM音色語彙、シンセ方式、質感語を混ぜるとSunoで伝わりやすい。

Synth engines音作りの方向。
Samplers / Machinesビートとサンプル感。
Electric / Electromechanicalポップ・R&B・ロックの基本。
Voice electronics声を変える。
FX / Sound design空間と異物感。

Suno prompt examples

darkwave synths, analog bass, gated reverb drums, icy pads, gothic atmosphere
granular ambient, evolving synth pad, tape loops, distant bells, no beat
hyperpop, bright synth lead, glitch drums, vocal chops, sidechain bass, sparkling chaos

Orchestra Families / オーケストラ編成

西洋オーケストラの実用軸。弦/木管/金管/打楽器/ハープ鍵盤を選ぶだけで曲の輪郭が決まる。

Strings和声・哀愁・厚み。
Woodwind色彩と空気。
Brass英雄・重厚・軍楽・不穏。
Percussion迫力・舞台・儀式。
Harp / Keyboards / Choir天上感、宗教感、和声。

Suno prompt examples

cinematic orchestra, low strings ostinato, muted brass, timpani, choir pad, dark heroic mood
fairytale orchestration, celesta, harp glissando, pizzicato strings, soft woodwinds

Regional Palettes / 地域別楽器パレット

Sunoでは“地域名 + 楽器名 + 役割”が非常に効く。単なるethnic/worldより具体楽器を置く。

日本・東アジア雅楽、寺院、民謡、映画音楽に。
中東・ペルシャ・トルコ旋法、砂漠、祈り、舞踊。
南アジアラーガ、ドローン、タブラ。
ケルト・北欧・バルカン笛・弦・ドローン。
アフリカポリリズムと共鳴。
ラテン・カリブ踊りと明るい打楽器。

Suno prompt examples

Celtic dark folk, uilleann pipes, fiddle drone, bodhrán, low male vocal, misty atmosphere
Latin cinematic groove, congas, bongos, timbales, nylon guitar, brass stabs, warm night air

Prompt Roles / Suno向け役割分類

楽器名より“曲中で何をさせるか”が重要。Lead/Drone/Rhythm/Bass/Pad/Sparkle/Textureで組むと破綻しにくい。

Lead / 主旋律耳に残る線。
Drone / 持続音宗教・瞑想・不穏の土台。
Rhythm / 拍身体性と様式。
Bass / 低域重心。
Harmony / Pad厚みと場。
Sparkle / 装飾きらめき。
Texture / FX異物感、現代感。

Suno prompt examples

sacred devotional chant, male unison choir, frame drum rhythm, low harmonium drone, hand claps, long reverb
gothic neoclassical, cello lead, pipe organ drone, chamber strings pad, bowed cymbal texture, church bells sparkle

Techniques & Texture / 奏法・質感語

楽器名に奏法を足すと解像度が上がる。現実の演奏語と生成AI向け質感語を分けて使う。

Strings techniques弦の質感を強く変える。
Winds techniques息と特殊音。
Percussion techniquesヒットの質感。
Keyboard / Experimental不穏・現代音楽。
Production / Space録音空間はプロンプトの味。

Suno prompt examples
